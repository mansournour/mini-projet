# 🌐 Mini-Projet Symfony — Cours de Développement Web

> Projet réalisé dans le cadre du **cours de Symfony** à **l’École Supérieure Privée d’Ingénierie et de Technologies (ESPRIT)**, durant les premières semaines d’apprentissage du framework.

---

## 🎯 Objectif du projet

Ce mini-projet a pour but d’appliquer les notions de base du développement web backend avec **Symfony** :

- ⚙️ Création et gestion des **routes et contrôleurs**
- 🧩 Définition des **entités Doctrine ORM**
- 🗄️ Intégration d’une **base de données MySQL**
- 🧾 Création et validation de **formulaires Symfony**
- 🎨 Utilisation du moteur de templates **Twig**
- 🔄 Gestion des **relations entre entités** et **migrations**

---

## 🧠 Technologies utilisées

| Élément | Détail |
|----------|--------|
| 🐘 **Langage principal** | PHP 8.2 |
| 🧩 **Framework** | Symfony 6.4 |
| 🗃️ **Base de données** | MySQL |
| 🎨 **Moteur de templates** | Twig |
| ⚙️ **ORM** | Doctrine |
| 💻 **Serveur local** | Symfony CLI |
| 🧱 **IDE utilisé** | VS Code / PhpStorm |
| 🔄 **Gestionnaire de dépendances** | Composer 2.x |
